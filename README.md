## Install
1. Download `FlickBinge.apk` from the link above.
2. Open the file. If Android asks, allow **"Install unknown apps"** for your browser / Files app.
3. Tap **Install** (or **Update** if FlickBinge is already on the phone — your data stays).
4. Open the app → **Create account** → your free trial starts.

Every new version is published here as a GitHub Release with the file named `FlickBinge.apk`,
so the link above always gives the newest version.

Need help or premium? Use **Contact admin** inside the app or on the website.
